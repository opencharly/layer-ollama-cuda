# 2026.329.2345 — feat(ollama-cuda)!: install the backend driver-free

## Summary

`ollama-cuda` depends on **`opencl-nvidia`**, the driver package. Installing it plainly bakes the
three driver libraries *and* collides with the ICD file the CDI contract writes, so the class-2 pod
build fails:

```
error: failed to commit transaction (conflicting files)
opencl-nvidia: /etc/OpenCL/vendors/nvidia.icd exists in filesystem
```

The package arm is replaced by a **run step** that installs the backend with the dependency treated
as satisfied:

```
pacman -Syu --noconfirm --needed --assume-installed opencl-nvidia ollama-cuda
```

The pod receives the driver from the host through CDI — the same driver-free-at-the-source pattern
opencharly/layer-cuda#41 introduced for `cuda`/`cudnn`.
